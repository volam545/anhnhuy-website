# ANY Fruit – Website package

## Included
- `index.html` — responsive bilingual Vietnamese/English website
- `assets/` — logo and photo assets used by the site
- Embedded YouTube introduction video

## Publish to GitHub Pages (phone or computer)
1. Open the GitHub repository `anhnhuy-website`.
2. Open the repository's root folder and choose **Add file → Upload files**.
3. Upload `index.html` and the complete `assets` folder from this package. Keep the folder name exactly `assets`.
4. If GitHub asks to replace the old `index.html`, choose replace/commit changes.
5. Open **Settings → Pages** and make sure the source is **Deploy from a branch**, branch **main**, folder **/(root)**. Save if needed.
6. Wait for the Pages deployment, then open the published website.

## Important
- Do not upload only `index.html`; the logo and photos are inside `assets/`.
- The website uses the contact details and YouTube link supplied for this project.
- `anhnhuy.com` will show the new site only after the domain is correctly connected to GitHub Pages and DNS has propagated. This package does not change your GitHub repository or domain settings automatically.
